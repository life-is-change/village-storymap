村规平台数据处理工具
====================

1. 双击“启动村庄数据处理工具.cmd”。工具会自动启动已有的两个 Conda 环境，不会创建新环境。
2. 浏览器打开后，填写村庄名称和英文标识，粘贴边界文件与卫星影像 GeoTIFF 的完整路径。
3. 保持默认的 OSM、哥白尼 DEM、模型配置和权重路径，点击“开始一键处理”。
4. 等待页面显示“处理完成”。成果位于本目录 output 下，同时生成文件夹与 ZIP 备份。
5. 登录村规平台管理员后台 → 村庄与项目 → 第 2 步，选择解压后的成果文件夹。

注意：
- 后台导入请选择成果文件夹，不要选择 ZIP，也不要上传原始 GeoTIFF/PBF/DEM/模型权重。
- 第一次建筑识别会加载 GPU 模型，时间较长属于正常现象。
- 若浏览器意外关闭，可重新访问 http://127.0.0.1:8031/ 查看任务状态。
- 3D 实景模型不放入 V0 数据包，应在学期中期从管理员后台的独立 Cesium 区域发布。
