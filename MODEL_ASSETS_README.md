# Curated Model Assets

This branch is intentionally asset-only. It does not contain or modify the teaching-platform code.

## Current batch
- 24 GLB models
- Selection is component-driven, not pack-driven.
- Focus: seating, tables, lighting, playground equipment, market/event props, municipal props, landscape features, boundaries and traffic details.
- Nature assets are intentionally minimal.

## Folders
- `models/kenney/` — selected CC0 Kenney models
- `models/leonkin-playground/` — CC0 slide and swing
- `catalog/asset_catalog.json` — curated index
- `ATTRIBUTION.md` — source/license notes

This is the first screening batch. It is meant for visual inspection before a larger library is assembled.
