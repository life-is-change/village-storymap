# Curated Model Assets

This branch is intentionally asset-only. It does not contain or modify the teaching-platform code.

## Current library
- **100 independent GLB assets**
- **24 editable scene-combination templates**
- **24 combined GLB files** for quick preview / top-view rendering / future 2D insertion
- Selection is component-driven, not pack-driven.
- Nature assets are intentionally kept limited.

## Main categories
- seating / tables
- shade structures: gazebo, pergola, awnings, event tents
- playground and fitness
- lighting
- market/event equipment
- signage / cultural display
- municipal / traffic
- landscape / paving / planters / boundaries
- waterfront bridges and steps
- limited vegetation

## Folders
- `models/kenney/` — selected CC0 Kenney models
- `models/leonkin-playground/` — CC0 playground assets
- `models/green-diamond/` — curated assets with per-model licenses recorded in catalog/ATTRIBUTION
- `models/combinations/` — generated combined GLB scene groups
- `catalog/asset_catalog.json` — independent-asset index
- `templates/scene_combinations.json` — editable group definitions
- `ATTRIBUTION.md` — source/license notes

## Two forms of combination assets
1. **Editable template form**: keeps every child asset editable and supports “place group → move/rotate group → ungroup → continue editing”.
2. **Combined GLB form**: convenient for direct preview, thumbnail/top-view generation and future 2D interface insertion.

The combined GLBs are generated from the editable template definitions and should not replace the editable source templates.
