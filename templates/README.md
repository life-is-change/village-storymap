# 组合场景模板

当前同时保留两种形式：

## A. 可编辑组合模板
文件：`templates/scene_combinations.json`

记录每个组件的：
- assetId
- 相对位置
- Y轴旋转
- 缩放

适合平台内实现：
**一键放入整组 → 整组移动/旋转 → 解组 → 继续修改单个组件。**

## B. 合并后的组合 GLB
目录：`models/combinations/`

每一个模板都有对应的独立 GLB，例如：
- `combo-gazebo-tea-corner.glb`
- `combo-pergola-rest-area.glb`
- `combo-playground-expanded.glb`
- `combo-small-stage.glb`

这一形式适合：
- Blender / Windows 3D Viewer 直接查看整体效果；
- 批量生成俯视缩略图；
- 后续在 2D 界面中以组合对象方式显示；
- 快速预览组合占地和视觉关系。
