# 组合场景模板

这些模板不是把多个 GLB 永久焊接成一个不可编辑模型，而是按“组合模型/场景组”的方式记录多个资产的相对位置、旋转与缩放。

这样更适合教学平台：
1. 一键放入整个组合；
2. 作为一个组整体移动/旋转；
3. 学生可“解组”后继续改单个组件；
4. 不需要学生从零摆放十几个小模型。

当前包含 12 个组合模板：
- 老年活动角
- 儿童活动角
- 乡村小市集
- 餐饮休闲角
- 喷泉休憩小广场
- 村口入口节点
- 安静休憩花园
- 步道休憩节点
- 公共厕所服务点
- 夜间照明休憩点
- 市集入口组
- 台阶景观节点

文件：`templates/scene_combinations.json`

其中坐标是初始推荐值，接入平台后可根据你现有场景编辑器的尺寸单位做一次整体校准。
