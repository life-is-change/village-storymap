在 4090 上的 Docker 网页使用：
1. 将压缩包复制到服务器，解压到一个单独目录，不覆盖仓库其他文件。
2. 进入解压后的 frontend-fix 目录，执行：
   sudo bash apply-web-fix.sh
3. 网页按 Ctrl+Shift+R 强制刷新，重新打开生成器。
此脚本不重启服务，不改 8080/8081、Nginx配置或网址转发；校验目标确为本项目 web 服务后才写入。原脚本备份路径会打印。

这是当前容器的临时热修复：容器重建时文件会回到镜像版本。
正式持久更新应将两个修复纳入服务器源码并仅重新构建本项目 Web 镜像；本轮没有推送 GitHub或重建 Web 镜像。
