# 公共空间设计工作室浏览器验收清单

记录日期：2026-09-14。自动化契约已覆盖数据隔离、三维放置/拖动、二维同步、撤销、自动保存、冲突副本、里程碑、恢复与提交。已有数据库先执行 `supabase_SQL/MIGRATION - Scene Edit Admin Sandbox.sql`；全新数据库执行 `supabase_SQL/Scene Edit Studio.sql`。

## 桌面 Chrome / Edge

- [ ] 从左侧“方案设计与迭代”点击“开始场景设计”，工作台直接进入现有三维村庄，关闭后原视图恢复。
- [ ] 顶部平台工具条仍为原有单行布局，“图层与项目管理”没有被挤到下一行。
- [ ] 管理员未加入小组也能创建本人独立沙盒，且不能与其他管理员或学生方案串数据。
- [ ] 不同小组、空间和账号互不读取或覆盖草稿；切换上下文时工作台自动关闭。
- [ ] 自由绘制有效公共空间边界；越界、自交和现状建筑碰撞有明确反馈。
- [ ] 放置点、线、面、小构筑物；图层隐藏、锁定和顺序正确。
- [ ] 多选、复制、删除、成组、对齐、等距、移动、旋转、缩放和节点编辑可撤销/重做。
- [ ] 端点、边、中点、现状与网格吸附；距离、角度、面积、宽高尺寸可读。
- [ ] 铺装拉伸、线性要素宽度与重复构件显示正确。
- [ ] 上传合法 GLB、校准真实尺寸并在 2D/3D 中复用；缺失模型显示带标签的替代体。
- [ ] 保存组合构件并复用；小组/课程分享副本和归档不影响已存在的版本快照。
- [ ] 3D 放置/水平拖动立即反映到 2D；2D 节点与面线编辑切回 3D 后同步；3D 高度/Z 缩放/俯仰/翻滚/材质不改变 2D 几何。
- [ ] 断网仍保留本机草稿；联网后可继续保存；并发冲突只出现三种明确选择且不丢数据。
- [ ] 创建带名称、说明、预览的里程碑；现状/当前/两个里程碑可着色对比。
- [ ] “恢复为新草稿”不覆盖来源版本；“提交此版本”只提交选定快照。
- [ ] 现状修订升级时创建新分支，旧方案和旧里程碑保持不变。
- [ ] 教师只读检查与素材下架流程符合课程权限，不出现学生编辑审批步骤。
- [ ] 原建筑更新、几何编辑、现有 3D 模型库与平台视图切换无回归。
- [ ] 网络面板不请求 `3D_scenes_edit/legacy/` 或 `building-assembler` 文件。

## 900 px 宽度

- [ ] 左侧图层/对象/版本、中央画布、右侧素材/属性区域无横向遮挡，右侧区域可下移使用。
- [ ] 工具栏可横向滚动，保存状态、冲突按钮和里程碑操作完整可见且可键盘访问。
