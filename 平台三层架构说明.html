浏览器

负责体验与渲染

网页 JS 在打开页面的电脑上执行；二维交互和 Cesium 三维画面使用该电脑的 CPU / GPU。

Supabase

负责身份、记录与协调

数据库、授权、对象存储和任务状态位于云端；不是 GPU 推理引擎。

Linux GPU 服务器

负责后台计算

Worker 主动领取任务，再调用内部 GPU 模型服务；结果回传云端，浏览器再读取。

GitHub 保存源码；GitHub Pages 或 Nginx 提供静态文件。静态托管地点与程序实际执行地点是两个概念。服务器有 4090，并不表示所有访问它的浏览器都由 4090 远程渲染。

任务状态不是一个同步请求

排队→领取 / 续租→执行 / 进度→上传成果→完成

失败、取消与租约丢失有独立分支。立面任务还存在人工确认阶段（如 awaiting_crop）。Worker 不能拿到任务后永远占有：租约和续租用于崩溃恢复；SQL 领取使用 SKIP LOCKED 等协调机制。具体时间与重试上限以实际迁移、参数和运行日志为准。

4090 如何“注册”与接受任务

服务器配置 WORKER_ID 和服务器端 Supabase 凭据，启动 Worker 后通过心跳 RPC 登记/更新在线状态，并主动轮询领取任务。浏览器查询近期心跳来判断相应能力是否可用；它不直接把请求发送到显卡，也不需要数据库保存显卡驱动。任务中的 worker_id 和阶段日志才是判断哪台服务处理任务的依据。

GPU 运算发生在 NVIDIA Container Toolkit 暴露设备后，PyTorch/CUDA 模型调用中。building 使用 CUDA 11.8 环境，facade-ml 使用 CUDA 12.4 环境；它们使用同一 GPU 时通过共享锁协调。道路/水系、DEM 处理、几何后处理、部分修复和 Blender 管线仍有 CPU 工作，不能把整条管线都归为 GPU 运算。

06

为什么是 Supabase，而不是“SQL”

SQL 是查询语言，PostgreSQL 是数据库系统，Supabase 是围绕 PostgreSQL 组织的一组后端服务。你目前已经在使用 PostgreSQL。

能力当前 Supabase 方式只安装 PostgreSQL 之后
关系与空间数据PostgreSQL + 按项目迁移启用的空间能力可以继续实现，需迁移扩展、结构、函数与数据
身份与 JWTAuth、用户资料和认证相关集成要保留原 Auth，或建立等价的登录、令牌和角色服务
API 与业务规则JS/Python SDK、REST、SQL RPC、RLS需提供 API 层、授权与原子操作；浏览器不应直接连接数据库端口
文件对象Storage 的桶、对象、权限和签名 URL需另建对象存储/文件服务，并迁移对象及引用关系
状态更新Realtime + 项目轮询兜底需保留轮询或另建事件推送与订阅服务
运维云端托管服务与现有项目流程自行管理备份、监控、更新、证书及可用性

本项目选择 Supabase 的价值在于已有业务能共用身份、数据库授权、文件与任务协调，减少重复搭建后台服务。它不保证每次请求最快，也不保证任何配置都合适。自建 PostgreSQL 可以是另一种部署选择，但必须比较完整链路和迁移成本。

迁移必须覆盖什么

不仅是表数据：还包括扩展、索引、SQL 函数与触发器、RLS 策略、身份与角色、对象存储文件及元数据、签名 URL 语义、Realtime/轮询、Worker 凭据与前端连接地址。仓库中的 SQL 脚本不能代替线上实际结构的导出和演练恢复。

把数据库放在 4060 或 4090 上，不会因为 GPU 型号而自动加速常规 PostgreSQL 查询。延迟、CPU、内存、磁盘、索引、查询形态与服务部署距离更直接影响这条路径。此次没有进行数据库迁移，也没有核对线上执行计划。

给师兄介绍时的完整表述

这个平台的展示层运行在浏览器：主平台以原生 JavaScript 为主，React 用于首页，OpenLayers 和 Cesium 分别承担二维与三维表达。逻辑层分布在浏览器模块、Supabase 的授权与事务函数，以及 Linux 的 Python Worker 和模型服务。数据层由 Supabase PostgreSQL、对象存储、服务器本地影像与模型文件共同组成。任务通过云端队列和 Worker 心跳协调，4090 承担服务器模型推理；用户看到的三维场景仍由打开网页的客户端 GPU 渲染。GitHub 管源码版本，Docker 管服务环境与部署，二者不替代数据库和模型输入管理。
依据：当前 working tree 的 ENTRYPOINTS.md、前后端模块、SQL 脚本、linux/ Dockerfiles 与 Compose、已保存性能实验。复用并更新 2026-10-07 技术栈模块索引。此页不包含真实凭据或云端业务数据；外部官方链接仅点击后联网。生成于 2026-10-08。
