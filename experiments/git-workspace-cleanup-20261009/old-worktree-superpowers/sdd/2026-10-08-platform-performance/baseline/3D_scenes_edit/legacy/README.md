# 历史构建器只读参考

这里保存两份相互独立的建筑构建器历史副本，仅供模块二迁移通用交互思路。

- `git_pre_delete/`：来自 Git 提交 `008893caff37b0f6297ebc04318c8a5580b81685`，作为最小结构参考。
- `cong_0526/`：来自 `village-storymap聪0526/building-assembler/`，用于研究范围绘制、尺寸显示、旋转占地、承托约束、属性编辑与快照历史。

生产代码不得导入、嵌入或请求这两个目录。旧实现依赖 Three.js 0.128、全局状态和通配 `postMessage`；模块二只通过经过测试的独立模块重新实现可复用能力。建筑专属的楼层、墙体、屋顶和楼板支承规则不进入公共空间场景核心。

`provenance.json` 记录来源、文件大小和 SHA-256。任何归档内容发生变化都会让 `legacy-provenance.test.js` 失败。
