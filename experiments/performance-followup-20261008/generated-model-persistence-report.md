# 生成建筑模型刷新丢失修复（2026-10-09）

## 原因

主平台接收生成器 GLB 后原先仅建立临时 blob URL、写入页面内存并替换 Cesium 白模，没有上传模型库或持久保存建筑绑定。同一页面返回首页会保留内存；整页刷新会清空该状态。

## 修改

- 主平台使用现有 group-models 存储桶、group_model_assets 和 building_model_bindings 保存 GLB 文件及空间/建筑绑定。
- 同时保存缩放、旋转、高度、偏移、拉伸、基底吸附及生成模型尺寸。
- 生成器等待带 requestId 的保存确认，确认前保持打开；保存失败可重试或下载已有 GLB。
- 刷新后从稳定 storage_path 重新签名并恢复模型；编辑器也读取持久绑定，后续调整保留尺寸并同步内存缓存。
- 更新相关脚本版本参数。没有改动 4090 容器、端口或数据库结构。
