# 溪田村 · 村庄生活实验室（体验版07）

现已新增真实方案接入：主平台进入小组场景设计后，点击顶部“村庄模拟”，配置建筑/面域用途、道路与入口，在原三维场景运行并随场景方案保存配置和摘要。独立虚构村庄入口继续保留。详见 [接入使用说明](integration/README.md)。

本版综合动态行为讨论与大江户APK分析，补齐“空间组合→人物活动→有限成长→主动保留→方案比较”。新体验默认开启；已有动态方案左侧点“启用活动与成长”，或在来访情境里切换。入口仍为 village_game/index.html，VS Code Live Server 从仓库根启动后打开 /village_game/。

二维与三维使用同一套原创16×24像素人物：大头短身、深色轮廓与分层配色，共享衣着、行走帧、休息及工作道具。三维以脚底为锚点，放置在当前平面道路表面上方，选中放大不改变脚点；建筑可遮挡身后人物，姓名与交流提示位于头部上方。室内保留场所标记，活动发生时人物显示在入口/活动场所。建筑与地面仍是简化模型，整体美术尚未统一为像素村庄，未接入APK美术。

宗祠＋公共休憩、儿童场＋公共休憩、民宿＋餐饮＋游览设施形成三类组合。配套必须道路连通且锚点至各配套单程≤150米，有至少30分钟共同运营（人员有可达工作安排）。详情显示缺项、路径或运营不足；生效组合只对对应群体和适用活动给有限加成。这些阈值是教学假设。

同处开放公共空间的非同行人物可进行5分钟邻里交流、游客问询或手作交流。移动、吃饭、工作与接送不参与；活动期间冻结原自由活动计时，任务变化/关门会中止，完成才记录成果。人冷却90分钟、每日最多2次，设施每日最多4次。人物参与熟悉度是累计活动记录，暂不改变职业/家庭安排。

成功使用推动单设施的“初次使用→使用熟悉→运营稳定”：每人每设施每日最多一次；累计12次且平均体验≥60、36次且≥65触发阶段，最高2。阶段带来最多6点基础吸引力修正与小幅选择变化，岗位、容量和手动改造等级独立。用途改变清除该设施经验。失败无奖励。

周期结束可查看事件成果、组合条件及各设施变化。点“保留本轮成长并返回设计”将成果写入方案；一次结果只能应用一次。再次运行从保存的成长起点开始；未保留时重放起点相同。不同初始成长、人物/客源或行为规则会注明不宜直接解释成空间改进。成长随方案自动保存/导出，旧结果作为历史。

行为版本5，场景格式仍2；v6及旧对照工厂保留。第一版成长只覆盖有限使用经验与活动记录，未加入预算、工资、关系网络、返乡创业或真实预测校准。

本版设计：docs/superpowers/specs/2026-10-14-living-village.md。实际验证见对应acceptance文件。

# 溪田村 · 村庄生活实验室（体验版06）

本版加入需求驱动的概率选择、设施品质升级、公共空间偶遇交流，以及吸引力驱动的游客来访。无需大模型 API。新体验默认24户、72位居民，每日48位潜在客源，实际来访由分群吸引力、口碑和固定种子生成，不再是固定48人。

已有方案保留空间与原来的日程/客流模式。左侧“启用动态体验”可保留布局启用新机制（将原人数的两倍作为潜在客源，上限80，可再调整）。在“行为、来访与日历”可分别选择动态行为/日程对照、吸引力来访/固定客流。动态行为配固定客流适合单独比较设施服务能力；动态来访配相同潜在客源和种子适合观察方案的发展反馈。

点击公共设施，选择基础吸引力、等级1—3与适用的升级方向，然后应用改造或点击升级。舒适、文化、亲子方向改变选择偏好与体验，服务效率改变服务时长；升级容量仍受占地与到岗限制。更改方向需重新运行。基础设施选项只扩容，升级按钮会采用所选方向或该用途的首个适用方向。

点击人物，详情末尾显示饥饿、疲劳和社交需求，以及最近一次决策的理由和前四项候选概率；后续日程显示必要承诺，自由活动在执行时生成。游客同行组共用选择。居民的工作、上学、备餐与接送保持约束，弹性活动不得跨越下一项必要安排。吃饭降低饥饿，休息降低疲劳，重复到访和体验进入有限记忆。低龄儿童沿用既有家庭/庭院规则，完整的家庭陪同游玩暂未展开。

公共空间里不同同行组的人偶遇时可短暂交流，地图显示“···”，人物与事件栏记录交流。检查间隔5分钟，半径12米，持续5分钟，个人冷却45分钟，已关闭场所不开始新交流。不生成大模型对话，也未建立长期关系、返乡创业或完整事件树。

左侧显示分群与综合吸引力，结算显示各日客源、实际来访、口碑、活动体验与偶遇次数。基础吸引力默认50，评分和概率系数均为教学假设。无路可达、无可到岗员工或没有运营时段的设施不贡献完整旅游供给；同类设施递减，可步行到达的互补设施有加成。体验指数考虑品质、等待、步行和失败，口碑每日缓慢更新。活动完成率不是满意度，不能单凭动态活动完成率判定方案优劣。

人物仍使用原有点标记；保留稳定身份、位置、动作状态和交互信息，后续可接自制/授权像素人物。没有把APK资源复制进产品。真实浏览器视觉验收本轮因工具地址策略阻断未完成；已验证真实模拟、DOM流程、视图实体和HTTP入口，详见本版验收。

独立入口是 `village_game/index.html`。用 VS Code Live Server 在仓库根目录启动，打开 `/village_game/` 即可；也可用 `python -m http.server 5505 --bind 127.0.0.1` 后打开 http://127.0.0.1:5505/village_game/ 。平台主入口仍为根目录 index.html。

默认完整虚构场地600×460米，24个家庭、72位常住居民、24处公共/生产/旅游设施；模拟3天（周五至周日）。以下保留原体验版05的生活与空间规则说明；其对照工厂采用每日24人固定来访，本版新体验采用上文的48人潜在客源。采用岭南／华南教学情境，包含宗祠／村史堂、半月塘、塘边公共空间和村庄幼儿园。无需实地调研、在线底图或登录。

建设菜单分为居住住宿、生产经营、教育照护、公共文化、旅游游憩五类；卡片同时展示功能图标、模型缩略图、名称和容量单位。二维、三维和详情共用功能符号，修改用途后同步更新。同类模型共用屋顶、墙体与配色；这仍是轻量模型表达。农田有种植行和田边遮阴，活动场有开放游具，观景平台有栏杆与座椅，宗祠有厅堂与前庭门柱。临时集市由四组摊位组成，开放时展开棚盖、关闭时收拢。新布局将观景平台放到溪岸，助餐点放到生活区，集市放在生活道路旁。地图默认显示功能标牌，住宅标牌较小；公共标牌在密集处错位避让，住宅低优先可隐藏，选中项优先。二维用引线对应位置；三维用标牌选择和建筑轮廓定位。可切换功能标识、名称和白模，点击标牌直接选中设施。

新预设为2–5人家庭，包含年轻父母与幼儿、父母与两个孩子、三代家庭、老年夫妇、成年夫妇、父女或母子家庭。详情显示年龄和明确的家庭角色。18户林氏、4户陈氏、2户吴氏表达本虚构村的主姓，配偶可不同姓，这不是对全国村庄的统计结论。

先点清晨、上午、午间、下午、晚间等时段，观察全村生活。清晨从06:00开始，备餐也从此时启动。实心点表示室外，空心点表示室内人物的场所标记；在家和住宿不再完全隐藏。展示标记有稳定的小幅分散，不能把它当成屋内实际坐标。选择第二天，比较周末。时段跳转会按同一规则重放此前过程，统计不丢失。播放速度可调，人物可跟随，二维和三维共用方案、道路与模拟。

人物列表可筛选六类居民画像和三类游客；住宅和人物详情连接到家庭、岗位、厨房准备与后续安排。性别不决定职业和家务责任。居民家庭/工作餐食为主，游客按就餐时段使用餐饮；3–5岁幼儿工作日入园，家人送接，受教师、道路、时间和容量约束。小学、中学默认通过村外入口就读；新建匹配学段的教学点会重新参与分配。幼儿园只接收学前儿童。过夜游客保留床位到次日退房。老人按能力与日程选择生产、休闲、照料、卫生服务。

农田劳动者每轮按家与田之间的路网和个人速度选择午餐：单程≤10分钟返家，较远或无法返家时带饭；10分钟是教学阈值。带饭需要家庭早晨备餐。午餐后安排30分钟午休，再前往下午劳动。人物详情显示当前位置、午餐策略、后续安排和最近活动记录。送饭与库存系统本版未加入。

回到空间设计，新增、移动、改造建筑，调整用途、容量、岗位、开放时间与入口；需要可达道路。设施会自动进入候选选择，岗位从固定居民中重新分配，不能凭空增加工作人员。公共服务容量还受实际到岗、同行人数、时间和空间约束；不满足会等候、改选或记录原因。

在“全村概况与来访情境”修改每日来访0–80人、三种游客比例（和为100）、3/7天与起始星期。完成周期，比较九类画像、居民/游客活动完成率、平均步行、容量/时间/家庭支持等未满足原因及各设施。与最近完整方案比较仅在相同人物和来访情境下进行；变化情境单独说明，并用相同情境的村庄预设作参考。活动次数会重复计同一个人，比例不代表满意度。

方案自动保存到新版v2本地键；可导出、导入和刷新恢复。旧v1浏览器存档保持原样，存在时可导出旧版备份。主动导入旧版JSON会保留原空间，生成稳定家庭和新版规则，旧统计清除；需要自行补充教学、照料等设施。新版导入只支持本版虚构场地或旧版480×360场地，固定常住人口；非法文件不会覆盖当前方案。

已有v2方案会保留原有建筑、家庭与对照模式，可主动启用动态体验。体验新版溪岸、助餐和摊位布局需先导出备份，再在空间设计中点“恢复完整村庄”；该操作会替换当前方案并启用动态规则。旧家庭没有角色信息时明确说明关系未记录，不能从年龄和性别推断夫妻或亲子关系。新行为版本4独立于场景格式2；旧结果仍可读为历史，但需重跑后才能和新预设或新方案比较。旧v4/v5参照工厂保留，v6使用独立的新体验工厂。

规则采用教学假设，尚未校准成真实预测。00:00–06:00略过，人物位置、身份与住宿状态延续；备餐简化为一次早餐准备覆盖早餐/午餐/便当，不含库存价格；低龄儿童工作日接回后使用家中庭院，复杂陪同游玩暂未模拟。晚间影响统计为70米邻近住宅活动暴露（户分钟），不代表实际声学量。无建设预算、车辆、疾病、工资、季节、真实村庄数据适配或云端协作。
