# 村庄规划互动平台迭代日志

> **过程文档**
>
> 本文记录平台代码、界面与功能的迭代过程，便于回顾“为什么修改、修改了什么、如何验证”。  
> 它与平台运行时采集的学生操作日志是两套独立记录：本文面向项目开发，学生操作日志面向教学研究与后台分析。

## 记录规则

- 每次形成一个可说明的功能调整后新增一条记录，不必逐行记录代码。
- 每条记录包含：目标、主要修改、影响范围、验证结果和后续事项。
- 尚未完成或尚未验证的内容要明确标注，不把设计设想写成已完成功能。
- Git 提交用于保存代码快照；本日志用于说明每个快照背后的产品与教学逻辑。

## 2026-07-17｜任务—情境一体化工作区（第一阶段）

**状态：代码调整已完成，待本次完整任务验收后由项目负责人决定是否提交 Git 存档**

### 迭代目标

在保留原有地图平台能力的前提下，解决“课程任务栏只是额外增加的一列”、2D/3D 与课程流程割裂、全局信息挤占对象信息区等问题。课程阶段用于提示当前情境和推荐操作，不作为限制学生探索平台的强制门禁。

### 主要修改

- 将课程结构整理为“2 个准备阶段 + 4 个实践阶段”：加入小组、学习准备、调研采集与现状校核、现状诊断与课堂汇报、方案设计与迭代、成果整理与提交。
- 最左侧保留可收缩的课程阶段栏；展开后优先展示当前阶段的成果、资料和建议操作，不再重复生成独立平台入口页。
- 地图上方增加稳定的情境栏，显示当前村庄、课程阶段、空间及小组信息；切换阶段只改变推荐关注点，不关闭其他已有功能。
- 取消“共建模式 / 规划模式”抽象切换，保留 2D / 3D 作为同一工作区的数据视图切换。
- 2D 与 3D 共用当前空间和对象上下文，切换视图时不再主动清除已选择的对象。
- 右侧固定为“对象信息与协作”，用于属性、照片和对象相关讨论；未选择对象时显示清晰的操作提示。
- 将全局图层、班级问题与留言、空间工具等集中到“图层与项目设置”抽屉，避免占用对象信息区。
- 问题标记与建筑、道路等普通矢量要素可同时浏览和交互；问题标记保持独立的点状入口，对象留言继续依附于选中要素。
- 修复首页内嵌页面尚未完成构建时绑定事件导致的初始化异常。

### 影响范围

- 课程阶段模型与最左侧任务栏。
- 平台主布局、顶部情境栏和项目设置抽屉。
- 2D/3D 视图切换与对象选择状态。
- 普通矢量要素、问题标记、班级留言和对象讨论的入口组织。

### 验证结果

- 新增课程情境、统一工作区交互和首页初始化时序的自动化测试。
- 已通过 Edge 本地页面结构与视觉复核：首页保持原有内容结构，平台可显示六阶段栏、情境栏、对象信息区及项目设置抽屉。
- 本条记录只描述项目代码迭代，不替代后台记录学生操作行为的运行时日志。

### 本阶段暂不处理

- 不修改 Supabase 数据表和现有云端数据。
- 不在本阶段实现教师后台、成果冻结提交及完整版本管理界面。
- 不把过程中的每个实施检查点单独作为 Git 备份；完整任务完成后再决定是否提交存档。

## 2026-07-16｜课程任务嵌入原平台（当前迭代）

**状态：已完成代码调整、自动化测试与本地服务验证**

### 迭代目标

解决独立“课程任务页”与原有 2D/3D 平台相互割裂的问题，让任务流程成为原平台的辅助导航，而不是新的跳转入口。

### 主要修改

- 移除独立课程任务主视图，不再为七个阶段重复展示平台入口卡片。
- 首页“进入互动平台”直接进入原有 2D 工作区。
- 在原平台最左侧新增课程任务图标栏，位于原“菜单”栏左边。
- 任务栏支持展开与收起：
  - 收起时保留约 68px 的七阶段图标导航。
  - 展开时显示当前阶段说明、建议步骤、小组加入和阶段完成按钮。
  - 浏览器会记住用户上次的展开/收起状态。
- 2D 与 3D 继续使用原平台内部的视图切换，不再设置“进入 2D 平台”“进入 3D 平台”等跳转按钮。
- 学生端不再展示“个人记录 / 最近操作”卡片；学生行为仍由后台活动日志记录。
- 点击任意课程阶段时，会展开任务详情，但不会离开当前地图工作区。

### 影响范围

- 首页进入平台的跳转逻辑。
- 原平台主布局的最左侧列。
- 课程阶段导航、任务说明和小组加入组件。
- 2D/3D 工作区的可用宽度与地图自适应刷新。

### 验证结果

- JavaScript 语法检查通过。
- 课程任务渲染与布局测试通过。
- 已验证源码中不存在独立课程任务视图及其跳转分支。
- 已验证首页入口会先读取课程上下文，再直接打开 2D 工作区。
- 本地服务返回正常，页面结构中已包含最左侧课程任务栏。

### 后续事项

- 在实际浏览器中确认不同屏幕宽度下的任务栏占用空间。
- 后续建设教师端学生行为查询与导出界面。
- 成果提交阶段仍需继续补充冻结版本、附件和教师反馈流程。

## 2026-07-16｜课程任务软引导与权限调整

**状态：已实施**

### 主要修改

- 七个课程阶段改为可自由查看，不再因前一步未完成而完全隐藏后续内容。
- 保留阶段进度记录，但将其从“强制门禁”调整为“学习提示”。
- 建立管理员与普通用户的基础权限区分。
- 准备课程、小组、进度和行为事件相关的 Supabase 数据表脚本。

### 说明

本次迭代解决了流程过严的问题，但独立课程页仍造成明显割裂，因此在下一迭代中改为嵌入式任务栏。

## 2026-07-15｜任务驱动课程工作台第一阶段

**状态：原型已实施，后续已被嵌入式任务栏结构替代**

### 主要修改

- 将教学实践初步整理为七个阶段：加入小组、学习准备、调研采集、现状诊断、方案设计、协作评审、成果提交。
- 建立课程、小组、任务进度与操作事件的前端服务模块。
- 为线下预先组队、学生自由加入和教师建组预留数据结构。
- 增加课程相关的自动化测试与 Supabase 建表脚本。

### 迭代结论

任务阶段本身有价值，但单独建立课程工作台会重复原有功能入口。后续保留任务模型，取消独立工作台页面。
