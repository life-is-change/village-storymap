# 独立本地认证开发验收

这份记录属于新版自主后端的开发证据，不是阿里云部署完成声明。暂不操作旧网站或候选容器；最终操作命令随统一交付包提供。

## 已通过的基础认证证据

固定 GoTrue `v2.197.0`，Linux amd64 镜像摘要 `sha256:839f529492d116b4e8b7777c953a27c381d34c15a744b1bcefde5eefaa1f9f9f`。原始 Auth 数据离线检查只输出计数及迁移版本，不保存或输出哈希/账号行；现有旧备份中四个密码账号、四条 email identity 均在支持范围，缺失迁移为零。新备份仍须重新检查。

GitHub 原生测试 [39465480356](https://github.com/life-is-change/village-storymap/actions/runs/39465480356) 在提交 `6d2f444` 通过：真实 GoTrue、原生 PostgreSQL、预先导入的 bcrypt 用户、UUID 保留、密码登录、并发注册资料初始化、metadata 不能授予管理员、刷新、退出、容器重启、旧站令牌拒绝。Auth runtime 没有 schema DDL、public 业务表读取或超级用户权限；单独迁移角色执行上游 schema migrations。

这些测试使用隔离账号。用户原密码在实际阿里云候选上的隐藏输入验收仍待部署后进行。现有旧桥接镜像不能据此当作新版镜像启动。

## 私有账号恢复契约

不增加公开密码重置路由。最终统一部署工具将包装短时运维命令 `auth/recovery-cli.mjs`，由拥有阿里云私有部署目录的操作者执行；普通 API 容器不挂载 Auth 签名密钥。命令使用成熟 GoTrue Admin API 修改密码，jose 只生成内部 Admin API 所需的 30 秒 service-role 凭据，不签发应用用户会话。

管理员每次运行均需隐藏输入当前网站密码，重新通过本地 Auth 验证，并由本地数据库检查有效管理员身份。目标账号、操作编号和新密码的服务端 HMAC 绑定；没有明文密码进入审计、命令行参数、镜像或日志。管理员每小时最多三次新操作，两次新操作至少间隔 30 秒；重放同一操作不会重新修改密码。完成凭据有效五分钟。

命令仅恢复学生/教师账号；管理员账号（包含操作者自己）不在这个恢复入口的范围内，防止管理员之间相互接管以及恢复过程锁死自身再认证。管理员自身忘记密码时需要另行核实服务器所有权的人工恢复，不能把这一入口宣传成已提供管理员紧急恢复。原来的网站也没有合成邮箱找回密码流程。

接受恢复操作后，目标账号的业务会话立即暂停；完成时撤销该账号全部 refresh token 和 session，保留 UUID、照片和记录归属。提供商响应丢失时保留 unknown 状态，禁止盲目重提；操作者用同一操作编号及相同新密码显式核对后才完成收据。账号停用同步禁止本地 Auth 登录并撤销会话，不删除 Auth 用户。

运维包装脚本、受信任 HTTPS IP、全量新快照/文件、本地任务队列及真实 4090 验收仍属于后续统一交付任务。原 Pages/Supabase 配置不改，新增本地数据不会自动写回原站。
