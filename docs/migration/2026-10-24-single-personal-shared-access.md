# 2026-10-24 单一个人空间与共享权限

## 用户规则与原因

- 移除管理员和普通账号的独立“个人图底空间”入口，避免个人体验、图底、小组与全班空间混淆。
- 图底成果先预览，可明确应用到“我的个人体验空间”，或清除预览。已有历史成果仍在个人体验空间的版本面板中可选。
- 应用仅替换所选成果包包含的整个图层，其他图层保留；界面说明覆盖范围。再次应用同一版本不会覆盖其后的手工修改。要切换成果可选择其他历史包。
- 所有正常登录的有效账号都能查看当前已发布村庄的全班共享现状；普通账号加入本课程真实小组后才能编辑，管理员无需入组。未入组教师同样只读。
- 原有冻结、只读、个人所有者与小组隔离规则继续执行。不会把其他课程的小组资格当作本课程编辑资格。
