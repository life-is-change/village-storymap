# 2026-10-24 单一个人空间与共享权限

## 用户规则与原因

- 移除管理员和普通账号的独立“个人图底空间”入口，避免个人体验、图底、小组与全班空间混淆。
- 图底成果先预览，可明确应用到“我的个人体验空间”，或清除预览。已有历史成果仍在个人体验空间的版本面板中可选。
- 应用仅替换所选成果包包含的整个图层，其他图层保留；界面说明覆盖范围。再次应用同一版本不会覆盖其后的手工修改。要切换成果可选择其他历史包。
- 所有正常登录的有效账号都能查看当前已发布村庄的全班共享现状；普通账号加入本课程真实小组后才能编辑，管理员无需入组。未入组教师同样只读。
- 原有冻结、只读、个人所有者与小组隔离规则继续执行。不会把其他课程的小组资格当作本课程编辑资格。

## 前置部署

用户已回传 `workspace_edit_consistency_repaired_browser_check_required`。本修复在该已知覆盖层上继续，保留最初发布、备份、回执和历史覆盖层的字节证明。

数据库新增个人结果存储到规范个人体验空间的关联，以及已应用图层版本标记。旧结果、照片和模型文件不删除，也不自动覆盖现有个人编辑；新应用成果使用带版本的对象编号，避免与旧照片、模型编号串联。

内部图层版本表保留作成果历史，不再作为独立可选空间。应用所选成果包在一个数据库事务内完成，并与编辑锁隔离；前端应用时阻止新编辑，已有草稿要求先处理。普通账号只读状态由服务端按实际身份计算，不依赖前端隐藏按钮。

## 浏览器验收

更新后强制刷新：

1. 未入组普通账号可进入全班共享现状并查看建筑、照片和留言，但不能保存几何、属性等共享修改。

4. 空间下拉不出现“个人图底空间”；生成成果可预览、清除预览或明确应用到个人体验。历史成果入口位于个人体验的版本面板。
