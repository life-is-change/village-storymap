# 学生模型与低配置运行：完成记录

2026-10-13。修改位于原项目目录的 `main`，尚未提交或推送。单文件自动生成高低模型已接入三个入口；学生无需安装 Node.js 或使用下文的可选离线工具。

## 自动流程（本次补齐）

学生上传一个 GLB → 浏览器 Web Worker 用 CPU 生成高模与低模 → 原件、高模、低模一并上传现有共享存储 → 保存模型绑定/素材元数据 → 组内其他成员下载并按屏幕占比自动切换。这条流程同时用于普通建筑替换、场景设计素材上传、照片贴图模型“替换原建筑”。

高模保留源模型的几何与贴图精度；低模减面目标 35%，普通贴图最大边 512 px，保留 PNG 透明通道。所有版本共用底部中心原点和单位，不因切换精度而移动位置。原件逐字节另存。生成失败或任一必需文件上传失败会中止登记，回滚本次已上传文件。

选中对象仍优先加载，但有低模时拉远也会使用低模。切换阈值有 15% 缓冲区，避免在临界距离反复加载。重新加载高模和低模时均刷新过期安全链接。贴图生成器等待保存确认上限为 420 秒，避免慢设备还在处理时提前报失败。

处理依赖已打包在 `assets/vendor/model-optimizer/automatic-model-worker.js`，浏览器从本网站加载；无需连接 npm/CDN，也无需新增 4090 服务。初次上传需要处理和上传额外文件，其他组员查看不重复生成低模。

## 已实现

- 设置中的“三维画质”：流畅优先、均衡、精细。配置保存在当前浏览器；主地图、实景小窗、照片模型预览按画质调整渲染。
- 普通建筑替换和场景设计都按屏幕占比、视野和选中状态加载模型。选中优先，加载最多同时进行两项；三档每个模型管理器的驻留预算分别为 12、24、48。预算分别管理，不是整个网页所有模型的总数。
- 有独立低模时，远处使用低模、近处使用高模；没有低模时，远处使用白模或简化代理。移出视野的缓存仅占用剩余预算，必要时释放。切换空间、清空或失效加载会释放模型资源，加载失败回退代理。
- GLB 上传使用浏览器 Worker 计算真实顶点边界，把底面中心设为原点，并按指定单位换算米制。普通建筑替换和场景设计共用这套处理，原始文件另存备份。归一化模型不再用包围球估计底部。
- 复用模型库资产和刷新恢复都会保留归一化尺寸、贴地参数及低模路径；重新应用其他资产会清除上一模型的参数。水平偏移、旋转和高度偏移后的实际位置参与视野判定。
- 预览按需渲染，隐藏时暂停；替换模型释放不用的几何、材质和贴图。实景小窗按画质控制分辨率与细节。

这是一套模型分级与按需加载机制。它不会自动把整个村庄制作成完整的 3D Tiles 空间金字塔，也不会自动替既有云端模型减面。

## 如何使用

1. 启动本地平台，刷新页面；在设置里把“三维画质”切到“流畅优先”。
2. 普通建筑或场景设计上传窗口只选择一个 GLB，平台自动准备轻量版本并保存。普通建筑上传窗口仍可选择米/厘米/毫米。贴图生成器完成后点击“替换原建筑”，也会自动准备轻量版本。
3. 其他组员进入相同小组空间后，拉近加载高模、拉远加载低模；刷新重新进入仍读取已保存的模型路径。超过当前画质的驻留预算时，部分模型暂用代理，优先显示视野内和选中的模型。
4. 既有模型保持兼容；需要采用新原点/贴地规则的旧资产，应从原始文件重新上传。

### 可选：开发者在本机生成高低模型

下面的命令是独立资产批处理工具，不是学生上传操作的要求。

需要 Node.js 22 或更新版本。第一次安装，在项目根目录执行：

```powershell
npm --prefix tools/model-processor ci
```

然后运行，输出目录必须是尚不存在的新目录：

```powershell
node tools/model-processor/cli.mjs --input "D:/models/house.glb" --output "D:/models/house-web"
```

输出 `original.glb`、`high.glb`、`low.glb`、`manifest.json`。默认高模不减面、贴图最大边 2048；低模减面目标 35%、贴图最大边 512。拓扑和部件保护会限制实际减面量，清单如实记录结果。工具使用 CPU；浏览器显示仍使用访问者自己的显卡。无需新增 4090 任务服务。

支持自包含 GLB，已有 Meshopt 几何压缩可先解码。带蒙皮或 POSITION 形态目标的模型请先导出静态姿态；Draco 输入请先导出未压缩 GLB。完整参数及限制见 `tools/model-processor/README.md`。工具目前是本机离线流程，不是自动上传或服务器任务队列。

python -m http.server 9010 --bind 127.0.0.1
