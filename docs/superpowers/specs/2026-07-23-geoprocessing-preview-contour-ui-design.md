# 个人图底生产体验修正设计

## 目标

修正任务临时预览与个人空间图层叠加造成的显示不一致，允许学生仅删除等高线，提供默认关闭的等高线数值开关，去除重复完成提示，并使生产面板融入平台现有视觉体系。

## 已确认行为

- 采用方案 A：临时预览保持独立，但必须跟随个人空间的建筑、道路、水系、等高线图层开关；保存成功后清空临时预览，只显示个人空间正式成果。
- 等高线只允许选择并删除，不允许新增、移动、旋转或修改节点；删除需点击“保存编辑”后写入当前个人版本。
- “等高线”和“数值”作为并列开关；数值默认关闭，等高线关闭时数值开关禁用。
- 任务完成提示仅在本次任务首次从活动状态进入 completed 时出现。恢复历史 completed 任务和重复 Realtime 消息不提示。
- 已保存任务显示“已保存到个人空间”，禁用重复保存按钮。

## 数据与安全

- `personal_layer_versions.editable` 对等高线继续为 `false`。
- `save_personal_feature_edit_batch` 仅额外允许 `layerKey=contours` 且 `action=delete`；其他等高线操作在数据库层拒绝。
- 为已经执行过个人空间 SQL 的项目提供独立增量 SQL，替换批量保存函数，不要求重建表。

## UI

- 生产面板采用状态条、选项卡片、两列参数区、主次按钮和成果卡片。
- 成果名称显示中文，保留要素数量和下载入口。
- 表单字体、圆角、间距、色彩和按钮状态与现有绿色平台主题一致。
- 错误保留在面板消息区；Toast 只用于首次完成、保存成功和保存失败。

## 验证

- 单元测试覆盖预览可见性同步、保存后清空、完成状态去重、已保存状态、等高线删除权限和数值开关状态。
- 数据库安全契约测试覆盖“等高线仅 delete”。
- 完整运行现有前端测试与 JavaScript 语法检查。
