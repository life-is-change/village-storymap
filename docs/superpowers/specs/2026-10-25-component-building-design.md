采用扩展已有 facade 队列的方式：任务提交固定生成方式和用途，现有贴图默认行为不变，构件任务由新版 Worker 显式处理。复用现有 ML 服务，新增构件识别端点，避免另起 Windows Demo 数据库和公网推理服务。独立 Demo 的固定几何函数以来源清单迁入后端包。

## 边界

继续保留当前本地识别质量边界，不承诺任意建筑照片达到V3。矩形体块生成器不能冒充精确任意多边形占地：不支持的占地必须明确拒绝或要求改建模式，不能静默包围盒替换。屋檐、阳台等附属构件可超出主体边界，主体必须受约束。真实部署和GPU端到端验证要与本机测试区分。
