# 村庄全日生活中的乡村早市

用户已确认按沿村路展开、棚摊与地摊混合的方向直接推进。本设计替代上一版“独立18人早市实验”的产品入口。

目标：虚拟村庄与真实村庄共用全日Life运行器、人物和时钟；现有家庭安排购物，真实摊主到岗后才接待，交流购买后沿路返家并继续后续作息。收市不结束全日。保持做饭、学校、陪同、正常岗位的安排；有硬性冲突则不插入购物，而非让人物分身。游客与儿童日程不被赶集覆盖。市场不可达、无人经营和收市都必须显式失败且继续当天生活。

推荐并采用在现有Life内加入早市任务与场内接待控制器。另一种将两个完整引擎拼接的方案会重建人物、时钟和家庭状态，不符合用户要求；只把模型替换成摊位则仍无实际行为，不能采用。

模型：市场是开放场地，不是建筑。统一以米生成摊位布置，混合约2.4米棚摊、3.4米长摊台、1.6米地摊；保持约0.5米间隔和中央通道，数量由场地可容纳长度决定。摊位长度、占地、货品和排队位一致。两端留出出入口；至少保留摊后到岗空间。虚拟村庄和真实场景共用布局数据，分别由现有本地实体与GLB渲染。预设只是可编辑起点，不覆盖已有自定义场地。

默认市场24×12米，06:30开市、09:30停止新接待、10:00收市。原有保存的市场对象直接获得新绘制与全日行为；旧独立演示草稿不覆盖原全日设计。真实场景已有早市布局保留，配置迁移为全日附带市场，人口、天数和游客设置不因启用市场而被强制改变。原有专门演示引擎仅为旧记录兼容保留，不作为产品入口。

不扩展支付、库存经济、专门摆货递菜动作、车辆。刚性摊位按地形锚点贴地，不宣称四脚自动适应任意坡度。本轮先实施并在本机验证；现有阿里云发布授权沿用，只有全部检查通过后发布更新。
