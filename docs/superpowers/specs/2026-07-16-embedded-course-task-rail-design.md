# 嵌入式课程任务栏设计

> **过程文档：** 本文件记录课程任务与原有 2D/3D 平台重新整合的设计依据，不属于平台运行文件。

## 目标

取消独立的“课程任务页面”，恢复原平台作为唯一工作界面。课程阶段以最左侧可收缩任务栏的形式嵌入 2D/3D 工作区，学生切换任务、编辑要素和切换视图时不离开地图。

## 布局

地图工作区从左到右固定为：

1. 课程任务栏；
2. 原有菜单栏；
3. 2D/3D 地图工作区；
4. 要素信息栏。

课程任务栏收起时宽约 68px，仅显示七个阶段图标、当前阶段高亮和展开按钮；展开时宽约 340px，在图标轨道右侧显示当前阶段详情。展开和收起不销毁地图实例。

首页不显示课程任务栏。学生点击“进入互动平台”后直接进入原有 2D 工作区；2D/3D 继续使用原平台已有的视图切换控件。

## 七个阶段

- 加入小组：显示组码输入、小组名称和成员状态。
- 学习准备：提示完成首页理论学习、村庄信息阅读，并允许记录完成状态。
- 调研采集：提供调研照片、地图定位和备注的操作说明，不再显示地图入口按钮。
- 现状诊断：提示使用地图问题标注、评论和问题清单。
- 方案设计：提示直接使用当前地图的要素编辑工具，2D/3D 为同一数据的视图切换。
- 协作评审：显示评审检查项和阶段完成操作。
- 成果提交：显示版本确认、方案说明和个人反思提示。

学生界面不显示原始操作日志或“最近操作”卡片。现有 `activity_events` 后台记录继续运行，供教师后台查询和论文分析。

## 数据与权限

未加入小组时使用原有公共规划空间；加入小组后使用小组共享空间。课程任务栏本身始终可见，加入小组仅决定数据空间归属，不阻止查看后续任务。

本次改造不新增数据库表，不修改已执行的 Supabase 课程表结构。

## 平台迭代日志

新增 `docs/PLATFORM_ITERATION_LOG.md`，明确标注为“过程文档”。每轮记录日期、目标、功能变化、涉及文件、数据库变化、验证结果和遗留问题。它与学生行为日志完全独立。

## 验收

- 首页进入平台后直接显示原有 2D 工作区。
- 课程任务栏位于整个工作区最左侧。
- 原有菜单、地图和要素信息栏继续可用。
- 课程任务栏可收起和展开，地图无需重新加载。
- 任务切换不出现独立课程页面、平台入口卡片或个人记录卡片。
- 2D/3D 使用原有切换控件，切换时课程任务栏持续存在。
- 学生操作仍写入后台活动日志。
