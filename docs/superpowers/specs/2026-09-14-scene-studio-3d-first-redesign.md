# 模块二：3D 优先公共空间场景设计改版

## 1. 决策背景

本设计修正 `2026-09-14-three-scale-studios-and-scene-editor-design.md` 中“二维主编辑、三维预览”的学生工作流。原有实现优先复用了 OpenLayers 的范围绘制与几何编辑，虽建立了统一场景文档和 Cesium 转换层，但不符合“学生直接在现有三维村庄中选择公共空间、摆放三维组件，再到二维校核”的预期。

本文件覆盖原设计的学生工作流、入口、三维交互、管理员范围和相关验收要求。原设计中仍适用的只读基线、差异方案、素材、版本、隔离与性能原则继续保留。

## 2. 产品目标

模块二是基于现有村庄三维场景的公共空间装配工具：学生在三维中完成选区与主要布置，二维是同一方案的同步俯视表达和精确校核视图。

首期目标：

- 不改变或覆盖全班共享现状、建筑白模和原有二维图层；
- 在现有 Cesium 村庄中圈定公共空间并放置场景资产；
- 在三维中选择、水平拖动、旋转、缩放、复制和删除离散资产；
- 切换二维后立即看到位置、朝向和占地轮廓，并可精确修改；
- 切回三维时使用同一份文档重建结果；
- 学生方案保持小组隔离；管理员不加入小组即可使用独立试用方案。

首期不实现 Blender/SU 级网格建模、地形挖填、实时多人同屏编辑或复杂物理模拟。

## 3. 入口与界面层级

### 3.1 课程入口

左侧课程任务中的模块二卡片提供“开始场景设计”按钮。该入口负责说明学习任务、检查身份与方案范围，并把主视图切换到三维。

不得再向 `workspaceContextBar` 添加“公共空间设计”常驻按钮。顶部工作区恢复原有九个控件的单行结构，不因模块二增加网格列。

### 3.2 三维情境工具栏

成功进入模块二后，在 Cesium 画布上显示模块二专用工具栏。工具栏只在模块二活动期间出现，至少包含：

- 圈定设计范围；
- 打开/收起组件库；
- 选择、移动、旋转、缩放；
- 复制、删除、撤销、重做；
- 保存里程碑；
- 退出场景设计。

工具栏是实际设计操作入口，不放入“图层与项目设置”。退出后恢复普通三维浏览控件。

### 3.3 二维切换

保留现有顶部“平面/立体”切换。模块二活动期间切换到平面视图不会退出工作室；OpenLayers 显示当前 SceneDocument 的设计范围、点状资产占地、线和面。切回立体视图后 Cesium 从同一 SceneDocument 更新实体。

不增加同时显示的小型二维窗口，避免压缩三维操作区域。

## 4. 身份与方案范围

### 4.1 学生

学生必须属于当前课程小组，并在本组 `group_plan` 空间中创建或恢复模块二方案。学生只能修改本组场景项目、素材和组件。

### 4.2 管理员

角色为 `admin` 的账号无需加入小组。管理员从正式村庄的共享现状空间进入模块二时，系统自动创建或恢复该管理员自己的“管理员试用方案”：

- 使用当前教学项目、村庄、共享现状空间及其基线版本；
- `scope_kind = 'admin_sandbox'`；
- `group_id` 为空，以 `created_by` 隔离不同管理员；
- 不出现在学生的小组方案列表中；
- 不修改共享现状，也不自动发布为课程素材；
- 允许管理员测试、演示和准备示例。

教师角色不自动获得管理员试用方案，除非后续另行确认。

### 4.3 数据库增量迁移

由于首版 SQL 已部署，改版必须新增独立、可重复执行的增量迁移，不要求用户回滚已执行脚本。迁移内容包括：

- 为 `scene_edit_projects` 增加 `scope_kind`，支持 `group` 与 `admin_sandbox`；
- 将 `group_id` 调整为可空，并增加约束：小组方案必须有 `group_id`，管理员试用方案必须无 `group_id`；
- 增加管理员角色判断和管理员试用方案创建/查询 RPC；
- 更新读写权限：小组方案仍按成员隔离；管理员试用方案仅创建者本人可修改，其他管理员默认不可修改；
- 更新索引，使管理员按教学项目、村庄、空间、创建者查找自己的活动草稿。

原始安装脚本也同步到最终结构，以保证新环境一次部署即可获得正确模式；已部署环境只执行增量迁移。

## 5. 3D 优先工作流

### 5.1 启动

1. 用户在左侧模块二任务点击“开始场景设计”。
2. 系统解析学生小组方案或管理员试用方案。
3. 主视图直接切换到 Cesium 三维场景并加载只读现状。
4. 加载该范围最新的 SceneDocument；没有方案时创建空的差异方案。
5. 没有设计范围时进入“圈定范围”；已有范围时直接进入“选择”工具。

### 5.2 三维圈定公共空间

- 用户在地形或地表上依次点击添加范围顶点，完成后形成闭合多边形；
- 地面坐标由 Cesium 深度拾取获得，失败时退回到椭球/地形射线拾取；
- 绘制过程中显示半透明范围和顶点；
- 完成时检查村庄边界、自交、最小宽度以及与现状建筑主体的冲突；
- 校验失败时保留可编辑草稿并明确标出问题，不创建场景对象。

### 5.3 放置组件

1. 用户从组件库选择资产；
2. 鼠标移入三维场景后显示半透明预览体；
3. 预览随地面拾取点移动，并显示占地轮廓；
4. 单击确认位置，生成一个 SceneDocument 对象；
5. 真实 GLB 可用时显示模型；不可用时显示明确的占位体，但仍保存正确类别和尺寸；
6. 连续放置保持当前资产激活，Esc 或“选择”退出放置。

### 5.4 三维编辑

- 单击场景资产进行选择，轮廓高亮；
- 拖动资产在地面上水平移动，拖动期间暂时禁用相机旋转；
- 朝向和水平缩放使用场景控件与数值输入，均产生可撤销命令；
- 高度偏移、俯仰、横滚和垂直缩放保留在三维属性中；
- 复制、删除、成组、撤销和重做继续使用现有命令历史；
- 每次有效命令立即更新场景文档、本地草稿、二维覆盖层和三维实体。

首期线、面节点的高精度编辑仍在二维完成；三维中可以创建范围、放置离散组件并调整离散组件。

## 6. 二三维同步规则

SceneDocument 继续作为唯一事实来源，不把二维和三维保存为两套方案。

| 三维操作 | 二维反馈 |
| --- | --- |
| 地面放置或水平移动 | 更新点位置与占地轮廓中心 |
| 绕竖轴旋转 | 更新二维占地朝向 |
| 水平缩放 | 更新二维占地尺寸 |
| 复制、删除、成组 | 同步对象数量和组关系 |
| 修改高度、俯仰、横滚 | 保持二维位置，属性中显示三维参数 |

| 二维操作 | 三维反馈 |
| --- | --- |
| 移动、旋转、水平缩放点状资产 | 更新 Cesium 实体变换 |
| 绘制/修改铺装、道路、绿地等线面 | 重建相应三维表达 |
| 隐藏或锁定图层 | 三维同步可见性，锁定对象不可编辑 |

关闭编辑工具后，当前小组空间或管理员试用方案仍可从数据库重新加载。普通现状空间永远不持久化这些差异对象。

## 7. 代码调整边界

- `index.html`：移除顶栏的 `openSceneStudioBtn`，保留独立工作室挂载点和脚本依赖；
- 课程任务 UI：在模块二任务卡提供 `data-scene-studio-open` 入口；
- `app.js`：入口改为先加载三维；解析学生/管理员上下文；保持模块二跨 2D/3D 切换状态；
- `3D_scenes_edit/integration/`：支持 `group` 与 `admin_sandbox` 两类上下文；
- `3D_scenes_edit/interaction_3d/`：新增 Cesium 范围绘制、地面拾取、预览放置、选择和拖动适配器；
- `3D_scenes_edit/preview_3d/`：从只读预览提升为可选择、可命中测试且增量更新的设计覆盖层；
- `3D_scenes_edit/ui/`：增加三维情境工具栏与组件面板，二维工具按视图显示；
- `3D_scenes_edit/domain/`：继续承载共享命令和几何校验，不依赖 Cesium/OpenLayers；
- `supabase_SQL/`：新增管理员试用方案增量迁移，并更新首装脚本。

不恢复或直接加载 `legacy/` 中的旧构建器，不修改原有建筑模型替换模块。

## 8. 异常与恢复

- 地面拾取失败：不落置对象，提示用户移动到可识别地表；
- GLB 加载失败：显示带名称和尺寸的占位体，不丢失对象；
- 保存失败：保留本机草稿并标记离线；
- 并发冲突：继续提供保留本地副本、载入远端、另存新方案三种选择；
- 切换教学项目、村庄、空间或账号：若作用域变化，关闭当前模块二会话并清理临时 Cesium 实体；
- 退出模块二：恢复原 Cesium 相机交互和普通 UI，不残留事件处理器或对象 URL；
- 管理员试用方案不得因空 `group_id` 被学生查询到。

## 9. 测试与验收

### 9.1 自动化测试

- 顶栏恢复九个原有直接子控件，模块二入口不在顶栏中；
- 模块二课程入口直接切换三维并显示情境工具栏；
- 学生无小组被拒绝，学生有小组进入本组方案；
- 管理员无小组创建/恢复自己的 `admin_sandbox`；
- 管理员试用方案不影响其他管理员和学生范围；
- 三维范围拾取、闭合与几何校验；
- 三维预览放置、选择、拖动、旋转、缩放和撤销；
- 每个三维变换更新统一 SceneDocument，并产生正确二维占地；
- 二维修改后 Cesium 实体同步更新；
- 退出与作用域切换完整清理三维交互与实体；
- 原有场景保存、版本、冲突、素材和平台 UI 回归测试继续通过。

### 9.2 浏览器验收

- 对比改版前截图，顶栏在左右栏各种展开状态下保持单行；
- 管理员不加入小组即可进入独立试用方案；
- 学生进入模块二后直接看到三维村庄和工具栏；
- 学生能在三维中圈定公共空间并放置至少一个真实 GLB；
- 三维移动、旋转、缩放后切换二维，位置、方向和占地一致；
- 二维校核后切回三维，模型更新且相机不被重置到无关位置；
- 刷新页面可恢复当前范围和已保存对象；
- 关闭模块二后普通2D/3D、建筑选择、模型替换和图层管理无回归。
