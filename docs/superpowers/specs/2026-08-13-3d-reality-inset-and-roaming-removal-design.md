# 3D 实景画中画与漫游功能移除设计

## 目标

在现有 Cesium 白模场景右上角增加独立、可交互的米埗村倾斜摄影画中画窗口。用户点击主场景白模建筑后，实景窗口自动定位到同编号建筑。同时完整移除过肩视角和无人机漫游功能，保留普通 Cesium 浏览、测量、建筑选择和视角重置。

## 已有条件

- 主 3D 模块使用 CesiumJS 1.118，入口位于 `app-3d.js`。
- 米埗村大疆智图 B3DM 成果已经作为 3D Tiles 成功上传至 Cesium ion。
- Cesium ion Asset ID 为 `5133927`，ion 预览加载正常。
- 主场景建筑矢量具有稳定建筑编号，可作为白模与实景代理层的关联键。

## 总体架构

页面同时维护两个相互独立的 Cesium Viewer：

1. 主 Viewer 保持现有白模、道路、测量和对象属性交互。
2. 实景 Viewer 位于主 3D 模块右上角的浮动面板中，加载 ion Asset `5133927`、地形和透明建筑代理层。

实景模型保留原始地理坐标，不做“东北方向”的地理平移。右上角仅表示界面位置。两个 Viewer 相机不持续联动；建筑选择通过建筑编号双向同步，主白模选择会额外触发实景相机跳转。

## 实景窗口界面

- 默认位于主 3D 模块右上角，不遮挡主要控制按钮。
- 桌面端采用约占主画面三分之一的尺寸，并设置最小、最大宽高。
- 标题栏显示“米埗村实景模型”和加载状态。
- 拖动标题栏可在主 3D 模块边界内移动窗口，本次会话内保留位置，不写入数据库。
- 在实景画布内保留 Cesium 默认的平移、旋转和滚轮缩放。
- 工具按钮包括全屏/退出全屏、重置实景视角、地形开关和关闭。
- 关闭只隐藏窗口并暂停持续渲染，不立即销毁已经加载的模型；重新打开可快速恢复。
- 主 3D 控制区提供“实景模型”按钮，用于重新显示窗口。
- 窄屏下窗口限制在可视区域内，并可切换全屏，不产生页面横向滚动。

## 模型与地形加载

实景 Viewer 创建后异步加载 `Cesium.Cesium3DTileset.fromIonAssetId(5133927)`。模型加载不能阻塞主白模首屏。

实景 Viewer 默认加载与主 Viewer 相同的地形策略。倾斜摄影自带地面覆盖核心区域，外部由地形提供空间背景。用户可关闭地形以处理高度穿插或遮挡；地形服务失败时自动回退到椭球体。

配置预留整体高度校准值 `heightOffset`。第一版不提供模型位置、旋转或高度编辑界面。

## 建筑匹配与相机跳转

实景 Viewer 加载一份当前空间建筑矢量作为透明代理层。代理实体：

- 使用与主白模相同的建筑编号；
- 不显示填充和轮廓，但保持可拾取；
- 使用原建筑高度或可用的默认高度形成相机定位包围范围；
- 不依赖倾斜摄影网格是否包含单体建筑元数据。

点击主 Viewer 白模建筑时：

1. 保持现有选中样式和属性面板行为；
2. 提取标准化建筑编号；
3. 在实景代理映射中查找同编号实体；
4. 显示实景窗口并将实景相机飞到代理实体；
5. 找不到匹配时仅显示非阻塞提示，不改变实景相机。

点击实景代理建筑时，同样选择主场景中的对应建筑并展示同一套属性。同步过程设置防重入标记，避免两个 Viewer 互相递归触发。

## 配置与权限

页面使用运行时配置：

```js
window.VILLAGE_REALITY_MODEL = {
  enabled: true,
  ionAssetId: 5133927,
  title: "米埗村实景模型",
  terrainEnabled: true,
  heightOffset: 0
};
```

复用现有 `window.CESIUM_ION_TOKEN`，令牌仅授予 `assets:read`。不得把具有 `assets:write` 权限的令牌写入前端或仓库。可用时，将令牌限制到所需资产和站点来源域名。

第一版不新增 Supabase 表，也不保存窗口位置或模型变换。

## 生命周期与性能

- 只在用户首次进入 3D 模块且实景功能启用时创建实景 Viewer。
- 主白模优先加载，实景模型后台加载并显示独立进度状态。
- 隐藏实景窗口后停止持续渲染；再次显示时请求一次渲染。
- 离开 3D 模块时暂停实景 Viewer，页面销毁时释放 Viewer、事件处理器和代理数据源。
- 对 3D Tiles 设置适合画中画尺寸的屏幕空间误差和缓存上限，避免与主 Viewer 竞争过多 GPU 内存。
- 全屏时重新计算 Viewer 尺寸并请求高质量渲染，退出全屏后恢复画中画性能参数。

## 异常处理

- ion 资产加载失败：窗口显示错误摘要和“重试”，主 Viewer 保持可用。
- 令牌缺失或无权访问：显示明确配置提示，不反复请求。
- 地形失败：回退椭球体，并保持地形开关为关闭状态。
- 建筑代理加载失败：实景模型仍可手动浏览，但禁用建筑自动跳转。
- 建筑编号缺失或无匹配：保持当前实景视角并提示“该建筑暂无实景对应位置”。
- 全屏 API 不可用或失败：保留普通浮窗，不影响 Viewer。
- 窗口拖出边界：在拖动和容器缩放时将位置约束回主 3D 模块内部。

## 漫游功能移除

完整删除以下专用文件：

```text
features/first-person/first-person-controller.js
features/drone/drone-controller.js
features/drone/assets/animated-drone.glb
features/DJIA.glb
```

同步删除：

- `app-3d.js` 中第一人称和无人机控制器的状态、初始化、同步、切换、事件拦截、销毁和公共导出；
- `app.js` 中漫游控制器脚本的延迟加载；
- `index.html` 中过肩视角和无人机按钮；
- `style.css` 中对应按钮选择器和专用样式；
- 当前 3D 操作提示中的漫游说明；
- `ENTRYPOINTS.md` 中已失效的漫游入口描述。

保留普通 Cesium 相机交互、3D 测量、建筑选择、重置视角，以及课程内容中与航测数据来源有关的“无人机影像”文字。历史修复记录不追溯改写。

## 测试与验收

### 静态检查

- 所有修改后的 JavaScript 通过语法检查。
- 仓库运行时代码中不再引用 `VillageFirstPersonModule`、`VillageDroneModule`、漫游按钮或已删除 GLB。
- `terra_b3dms.zip` 和解压目录不进入 Git。

### 主场景回归

- 进入和退出 3D 模块正常。
- 白模、道路、测量、建筑点击、属性面板和重置视角正常。
- 移除漫游后不存在缺失脚本请求、空按钮或残留事件监听器。

### 实景窗口

- Asset `5133927` 能够加载并显示进度、成功或失败状态。
- 标题栏拖动受主模块边界约束。
- 实景画布可独立平移、旋转和缩放。
- 全屏、退出全屏、关闭、重新显示和重置视角正常。
- 地形开关和地形失败回退正常。
- 隐藏窗口后不持续占用渲染循环。

### 建筑同步

- 有匹配编号的主白模点击后，实景相机飞到对应建筑。
- 实景代理点击后，主场景选中对应白模并显示属性。
- 缺失编号和无匹配编号不会抛出异常或移动到错误位置。
- 快速连续点击不同建筑时，以最后一次选择为准。

## 不在第一版范围

- 高斯泼溅格式加载；
- 模型地理位置、旋转或高度的可视化编辑；
- 将窗口位置或模型校准参数写入 Supabase；
- 单栋倾斜摄影网格的语义拆分；
- 两个 Viewer 相机持续同步；
- 移动端复杂手势定制。
