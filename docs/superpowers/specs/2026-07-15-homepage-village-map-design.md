# 首页村庄现状地图设计

> **过程文档：** 本文件仅用于记录方案讨论与设计依据，不属于平台运行文件。

## 目标

将首页“村庄现状内容区域”的占位内容替换为可交互的村庄信息与天地图影像地图，使访客能够阅读当前案例村简介、切换未来案例村，并在地图中浏览位置。

## 页面结构

保留“村庄现状”标题和三张概况卡片。卡片下方替换为双栏模块：左侧为村庄选择器和介绍，右侧为地图画布。桌面端采用约 40% / 60% 的比例；窄屏时纵向堆叠，地图置于介绍之后。

## 数据与行为

以一个 `VillageProfile` 配置数组管理村庄名称、介绍、坐标和缩放级别。首条为“米埗村”，内容采用谨慎的概览文案：其位于广州市从化区北部山区，乡村旅游是当地较突出的发展方向。选择条目时，左侧内容同步切换，地图飞行到该村坐标。默认展示米埗村。

地图使用天地图 JavaScript API 和项目既有密钥 `a2a034ff8616a35957abf8951339fedb`，显示影像底图及注记。地图右侧固定四项可访问操作：全屏、放大、缩小、返回主区域；返回主区域固定定位到广州市番禺区中山大学广州校区东校园（大学城外环东路 132 号）附近，而非当前下拉村庄。

## 组件边界

- `village-data.ts`：村庄类型、配置和默认主区域，便于未来新增村庄。
- `VillageMapSection.tsx`：加载天地图脚本、初始化/销毁地图实例、响应下拉项与控件事件。
- `App.tsx`：在村庄现状区引入新模块，移除旧虚线占位框。

## 异常与降级

脚本或地图瓦片加载失败时，地图区域展示中文提示而不是空白框；介绍与选择器仍可正常使用。首次脚本加载完成前展示轻量加载状态。重复挂载不重复插入脚本标签。

## 验证

构建通过 TypeScript 与 Vite 检查；静态检查确保地图配置和控件行为的纯逻辑可测试。浏览器验证包含：默认影像加载、米埗村选择、四项控件工作、窄屏布局和失败提示。
