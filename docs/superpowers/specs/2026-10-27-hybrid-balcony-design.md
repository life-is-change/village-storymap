# 混合阳台深度

用户已确认默认可用净深1.5m，采用内凹1.0m与约0.5m外挑。净深从玻璃外表面到前栏杆内侧；栏杆截面另算。只改变有凹阳台证据且有通行门的自动关系，不强迫普通窗成为凹阳台。底层主体、尺寸和朝向不变，上层允许外挑，记录非实测假设。

采用局部凹墙+连续混合楼板及三侧栏杆。纯凹1.5m缺少要求的外挑层次，纯外挑1.5m改变照片体量过大，均不采用。保留旧JSON旧规则，新增关系版本供新生成使用。输出各阳台净深与投影尺寸供现场验收。

本地原图缓存检测生成、Blender导出及几何尺寸核验后，制作基于已完成quality回执的小覆盖补丁。原部署包与ML不改，无模型下载；现场人工执行部署命令。
