# 响应式课程工作区 UI 调整设计（过程文档）

## 目标

让课程情境栏和对象信息栏处于任意展开/收起组合时，顶部工作区栏均保持单行、清晰且不遮挡；同时压缩项目设置抽屉，重新组织空间工具、问题标记与班级讨论。

## 顶部工作区栏

- 保持单行布局，不新增第二行。
- 阶段信息宽度压缩，空间选择器紧随其后，不再使用会吞掉剩余空间的无限伸展。
- 保留空间新增、重命名、删除以及 2D/3D 切换。
- 顶部仅保留“班级讨论”，移除“标记问题”。
- “图层与项目设置”在空间不足时收为齿轮图标，但保持可访问名称和悬浮提示。
- 根据左右栏实际可用宽度逐级压缩文字、间距和控件宽度，禁止设置按钮竖排或溢出对象栏。

## 图层与项目设置抽屉

- 桌面宽度由 380px 收为 320px，内部间距和按钮高度同步压缩。
- 模块顺序：图层控制、空间工具、问题与留言、导出。
- 空间工具位于问题与留言之前。
- 问题与留言提供两个独立按钮：“标记问题”和“班级讨论”。
- “标记问题”进入问题类型选择和地图点选流程；“班级讨论”展开并滚动到班级留言列表。
- 不再出现“新增问题标记或留言”的混合表达。

## 班级留言视觉

- 留言使用独立卡片；作者为强调文本，时间为弱化辅助文本。
- 正文采用 13px–14px 字号和 1.55 行距，允许自然换行。
- 点赞、回复和定位使用统一尺寸的轻量按钮，图标与数字对齐。
- 回复区使用浅色底和缩进，与主留言形成层级。
- 保留现有发言人、时间、点赞、回复和定位功能，不改变后端数据结构。

## 验证

- 静态结构测试覆盖顶部按钮、抽屉顺序和拆分入口。
- CSS 回归测试覆盖双侧栏展开时的紧凑规则、抽屉宽度与留言卡片样式。
- 运行现有全部 Node 测试，保证地图、课程和评论逻辑不回退。
