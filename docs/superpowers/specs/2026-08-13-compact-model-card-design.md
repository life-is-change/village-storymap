# 窄侧栏模型卡片设计

## 目标

让“可用模型”在 3D 对象信息侧栏中保持清晰、紧凑且无横向滚动，尤其适配长 GLB 文件名。

## 布局

- 卡片采用纵向信息层级，不让模型名和操作按钮争抢同一行宽度。
- 首行显示模型名称与文件大小；名称最多两行并允许断行，文件大小为紧凑标签。
- 当前建筑正在使用的模型显示“使用中”标签。
- 主操作“应用模型”占满卡片宽度。
- 删除操作放到卡片右上角，使用小型危险样式和明确的无障碍名称。
- 模型列表仅允许纵向滚动，禁止横向滚动。

## 交互与边界

- 保留既有应用、删除、权限及确认逻辑，只调整生成的标记和 CSS。
- 长文件名通过换行和溢出约束留在卡片内部；完整名称保存在 `title` 属性中。
- 空模型库、上传、刷新、从照片生成和恢复白模功能不变。

## 验证

- 集成测试检查卡片状态标签、删除按钮语义、纵向滚动与单列操作布局。
- 运行模型库集成测试、完整 `features` 回归测试和 JavaScript 语法检查。
