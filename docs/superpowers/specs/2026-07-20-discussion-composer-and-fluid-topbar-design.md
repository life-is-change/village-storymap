# 流式顶栏与班级讨论发布区设计

> **过程文档**：记录本轮界面修正的已确认方案，不作为 Git 存档。

## 目标

- 顶部空间选择器根据实际剩余宽度伸缩，不再保留无意义的右侧空白。
- 班级讨论模块直接提供留言输入与发表入口。
- 无回复的留言卡片不显示空白回复容器。

## 已确认交互

- 顶部依次保留阶段信息、弹性空间选择器、空间管理、2D/3D、班级讨论快捷入口和设置按钮。
- 抽屉的操作按钮区域只保留“标记问题”；“班级讨论”位于下方讨论模块中。
- 讨论模块标题下显示多行输入框与“发表留言”按钮。顶部“班级讨论”打开抽屉后聚焦该输入框。
- 回复容器仅在已有回复或用户主动点击“回复”后显示。

## 顶栏三级适配补充

- 不再仅根据“任意侧栏是否展开”使用同一套顶栏样式，也不再使用整个浏览器宽度决定设置按钮文字。
- 以中间地图工作区的实际宽度作为容器查询依据。
- 宽空间显示“班级讨论”和“图层与项目设置”的完整文字；中等空间将两者收为带提示的图标；狭窄空间进一步隐藏重复的阶段摘要并缩小空间管理与视图按钮。
- 空间选择器参与伸缩，但不会再独自承担全部宽度变化，所有控件不得溢出顶栏边界。

## 验证

- 用结构测试验证弹性顶栏、讨论发布区和空回复折叠行为。
- 运行现有全部 Node 测试与 JavaScript 语法检查。

## 四种侧栏状态的混合适配补充

单纯使用中央工作区宽度无法表达不同侧栏状态下的信息重复关系。顶栏因此采用“侧栏状态决定内容优先级，容器宽度负责防溢出”的混合规则。

### 左栏展开、右栏收起

- 左栏已经展示课程、村庄与当前阶段，顶栏隐藏重复的村庄和阶段摘要。
- 空间选择器接收固定操作槽位之外的全部剩余宽度，不保留无法利用的空白。
- “班级讨论”和“图层与项目设置”优先显示完整文字。

### 左栏收起、右栏展开

- 顶栏保留紧凑的村庄与阶段摘要，补偿左栏关闭后缺失的课程上下文。
- 空间选择器适当缩短，空间管理与 2D/3D 切换保持完整。
- 在容器宽度允许时完整显示“班级讨论”和“图层与项目设置”；不足时由容器查询退化为图标。

### 左右栏均展开

- 隐藏已经由左栏呈现的村庄与阶段摘要。
- 降低空间选择器的最小宽度，并压缩控件间距。
- “班级讨论”和“图层与项目设置”固定使用带标题提示的图标态，确保不覆盖右栏。

### 左右栏均收起

- 展示最完整的顶栏信息和两个文字按钮。
- 空间选择器弹性填满固定操作之外的剩余空间，使顶栏形成连续、稳定的控件序列。

### 适配与验证原则

- 明确的侧栏组合负责第一层布局；中央工作区容器查询作为第二层保险，处理缩放和较小屏幕。
- 四种状态都必须保证控件位于顶栏边界内，空间选择器、视图切换和设置入口始终可用。
- 回归测试分别覆盖左开右关、左关右开、左右均开、左右均关，并断言对应的完整文字态或图标态。

## 顶栏空间预算网格补充

最新复核表明，Flex 布局中的选择器最大宽度和自动外边距会同时造成两类临界问题：中间出现无法利用的空白，右端设置按钮却仍可能贴边或越界。本轮以网格空间预算替代这两个规则。

- 顶栏按“课程摘要、空间选择、空间管理、视图切换、班级讨论、项目设置”六个槽位组织。
- 除空间选择外，其余槽位按内容宽度占位；空间选择使用 `minmax(160px, 1fr)` 接收全部真实剩余空间。
- 左栏展开且课程摘要隐藏时，网格同步移除摘要列，不保留空列。
- 不再使用 `margin-left: auto` 制造操作区间隔，也不再为选择器设置固定最大宽度。
- 中央工作区接近临界宽度时，先隐藏“图层与项目设置”文字；继续缩窄时再隐藏“班级讨论”文字。
- 顶栏右侧始终保留不少于 14px 的安全内边距，按钮边框、圆角和阴影不得越过顶栏边界。

## 返回首页入口补充

- “返回首页”作为顶部工作区的第一个固定图标槽位，位于课程摘要与空间选择之前。
- 左侧课程情境栏标题不再重复显示首页按钮，标题区域仅保留“当前课程”和课程名称。
- 首页按钮保持 36px 固定尺寸，不参与压缩；空间不足时仍由空间选择器承担弹性收缩。
- 继续复用现有 `floatingHomeBtn` 标识和 `showVillageOverview()` 点击行为，不新增导航逻辑。
