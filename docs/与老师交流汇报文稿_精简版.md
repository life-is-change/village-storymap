# 与老师交流汇报文稿：乡村规划互动式学习平台（精简版）

> 建议汇报时长：8—10分钟。

## 一、为什么要做这个平台

老师，我想先从规划工作和规划教学的变化讲起。

过去的规划工作更多以专业人员调查现状、分析问题、绘制图纸和编制成果为中心，公众参与通常集中在调研、咨询或成果公示等阶段。现在，国土空间规划越来越强调统一底图、多源数据、协同工作、动态更新和全过程管理。乡村规划也不能只依靠规划师的专业判断，还需要理解村民的生活经验、空间使用、地方历史和实际建设需求。

规划教学也面临类似变化。传统课程本来就包括理论讲授、现场踏勘、访谈、现状分析和方案设计，但这些环节经常分散在课堂、纸质笔记、手机照片、微信群、GIS、CAD和建模软件中。教学流程虽然连续，资料和协作环境却未必连续，学生前期收集的材料进入设计阶段后可能难以查找，也不容易了解其他同学对同一对象做过哪些调查和修改。

AI的发展进一步改变了规划工作的技术条件。遥感识别、空间数据处理、大语言模型和图像生成可以辅助资料生产、整理和表达，也让学生直观感受到规划、GIS、遥感、三维技术和计算机之间的交叉。但AI不能代替现场核实和专业判断。因此，我希望平台不仅让学生使用新技术，还让他们理解机器结果怎样经过调查、校核和讨论，才能转化为规划依据。

## 二、为什么需要一个互动式平台

已有参与式规划研究说明，规划知识不仅来自规划师和教师，也来自村民对日常生活、空间使用、季节变化和地方问题的长期认识；WebGIS和三维可视化研究则说明，真实地点、地图和三维场景有助于学生理解空间问题。但是，有地图、有三维或有访谈，并不代表这些内容已经形成连续的学习过程。

我认为真正需要解决的是三个连接问题：第一，学生线下获得的访谈、照片和观察怎样与具体空间对象关联，并继续进入问题诊断和方案讨论；第二，个人调查、班级共同现状和小组方案怎样共享基础资料，同时保持清楚的数据边界；第三，平台怎样保留学生的修改、讨论和版本过程，而不是只呈现最后一张图。

因此，平台的意义不只是把若干工具集中到一个网页中，而是把真实村庄资料、课程任务、空间对象、学生协作和阶段成果组织成一个相对连续的学习环境。

## 三、我的研究定位和平台思路

我建议把论文主题概括为“面向乡村规划实践教学的互动式学习平台构建与形成性评价”。“规划教育”是研究背景，“乡村规划实践教学”是具体场景，“从调研内容到规划知识”则是平台希望支持并需要通过课堂检验的关键过程，而不是唯一的创新点。

核心科学问题可以表述为：

> 本研究面向乡村规划实践教学，整合真实村庄资料、学生实地调研、空间可视化、共享现状校核、问题诊断、二维与三维方案推演以及版本化协作，构建贯通“调研—分析—设计”过程的互动式学习环境，并通过平台日志、学习成果、问卷和访谈开展形成性评价，检验其教学适配性、协作支持作用及使用障碍。

平台中的角色需要准确界定。村民不直接使用平台，他们主要通过学生线下访谈和踏勘提供地方知识；学生是主要使用者；教师确定课程目标、分组原则和阶段要求；管理员根据与教师的沟通，执行创建村庄、分组、冻结现状和平台维护等操作。因此，它不是村民在线共同设计的平台，而是连接“线下参与式调研”和“线上学生协同分析与设计”的学习环境。

平台的总体思路可以概括为：

> 真实村庄资料 → 调研信息空间化 → 班级共同校核 → 小组方案推演 → 过程记录与评价

目前的核心机制包括：课程任务进入真实村庄；学生在个人空间生成和修订图底；全班共同校核现状；管理员按课程安排冻结共享基线；各小组从同一基线派生方案；学生结合二维地图和三维场景进行设计；平台保存对象修改、讨论、日志和方案版本。

目前平台已经实现了功能集成和部分流程衔接，但还不能直接说完全解决了“调研内容到规划知识”的转换。后续可以增加轻量的“证据—问题—策略”关联，使问题记录能够引用照片、访谈和空间对象，设计策略也能说明回应了什么问题。

## 四、平台可能产生的作用

对学生而言，平台可能帮助他们把抽象理论放入真实村庄情境，理解空间数据需要调查和校核，通过共享现状和小组方案学习协作，并利用二维、三维和AI辅助认识不同技术的作用与限制。平台也可能减少资料丢失、底图重复制作和版本混乱。但这些是需要课堂数据检验的作用，不能提前写成已经证明的教学效果。

对村庄而言，平台可以逐步积累数字底图、调查材料、现状校核和多届学生的方案，为后续课程、研究和交流提供可继续使用的资料基础。不过，它目前不是正式的村庄治理系统，学生方案也不会自动成为实施方案。

## 五、论文准备怎样组织

论文可以按照“问题—设计—实施—评价—反思”展开：首先说明规划行业、规划教学和AI时代的变化；其次梳理参与式规划、地方知识、WebGIS、三维可视化和互动平台研究；然后提出平台的分析框架和设计原则；接着介绍平台机制及真实课程实施；最后开展形成性评价并讨论局限。

课程预计有17名学生，不适合进行大样本推断，也不应在没有前后测和对照组的情况下声称平台显著提高了学习成绩。评价可以综合平台日志、学生操作记录、调研与方案成果、课程问卷和学生访谈，重点分析四个方面：平台是否适合课程流程，是否支持学生协作，调研证据是否进入后续设计，以及学生使用二维、三维和AI工具时遇到了什么优势和障碍。

论文的可能贡献不是发明新的访谈方法，也不是简单增加平台功能，而是提出一套连接真实调研、共同现状、分组设计和过程评价的学习环境；建立个人空间、班级共享基线、小组方案分支和版本记录的协同机制；并通过真实课堂案例说明平台怎样被使用、在哪些环节发挥作用、还存在哪些断裂。

## 六、平台操作流程

最后，平台的实际使用可以概括为七步：

1. 教师与管理员确定村庄、课程任务、分组和阶段安排，由管理员完成系统配置。
2. 学生进入课程单元和真实村庄，在个人空间生成、整理和修订基础图底。
3. 学生开展现场踏勘和访谈，将照片、观察和访谈内容关联到空间对象。
4. 全班共同补充和校核建筑、道路、水体及公共空间等现状信息。
5. 教师与管理员商定阶段节点，由管理员冻结共享现状，各小组从同一基线建立方案。
6. 小组开展问题诊断，在二维地图和三维场景中推演、比较和修改方案。
7. 平台保存讨论、操作和版本；课程结束后结合成果、问卷和访谈进行评价。

我希望老师重点判断三点：这个论文定位是否合适；共享现状、冻结基线和小组方案分支能否成为平台的核心机制；在17名学生的真实课程中，采用日志、成果、问卷和访谈进行形成性评价是否足够支撑论文。
