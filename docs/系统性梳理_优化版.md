# 乡村规划互动式学习平台研究系统性梳理

## 一 为什么要做这个平台

规划教育具有较强的实践性。学生不仅要学习理论和技术，还要在真实场地中取得证据、认识问题并形成设计判断。乡村规划课程通常已经包括理论讲授、现场踏勘、访谈、现状分析和方案设计，问题并不是缺少这些环节，而是它们分别发生在课堂、村庄、纸质笔记、微信群、GIS、CAD和建模软件中。课程流程虽然连续，资料和协作环境却未必连续，学生进入设计阶段后可能难以追溯某项判断来自哪次访谈、照片或观察，也不容易了解其他同学对同一对象做过哪些调查和修改。

WebGIS、遥感识别、二维三维可视化和AI为规划学习提供了新的条件，但技术进入课堂不等于学习过程已经贯通。机器生成的底图仍需现场核实，AI结果仍需判断，三维场景也不能代替问题分析。规划教学需要培养的，不只是工具操作能力，更是组织证据、核验数据和形成专业判断的能力。

因此，本平台不是为了替代现场调研和课堂指导，也不是简单集合多个工具，而是尝试围绕真实村庄和具体空间对象，将课程知识、现场调研、共同校核、问题诊断、小组设计和过程反馈组织成相互联系的学习过程。

## 二 相关研究的启发与不足

相关研究可以按照“调研材料怎样获得—空间问题怎样表达—不同阶段怎样衔接”三个层次展开。这些研究为平台提供了不同方面的依据，但研究对象和评价重点并不完全相同，不能简单概括为已有研究“没有解决”某一问题。

### 2.1 地方知识与参与式调研

参与式规划和PPGIS研究说明，村民对日常生活、空间使用、地方历史和建设需求的经验，是乡村规划的重要信息来源；地图可以将这些信息与具体地点关联，并支持后续讨论[1-2]。参与式行动研究和地方性学习进一步强调，学生应通过现场观察、访谈和共同讨论接触真实社区问题[3-4]。

不同受访者可能因年龄、职业、居住位置和个人经历而对同一空间作出不同描述，因此多份访谈并不会自动形成更“稳定”或更“正确”的判断。平台能够做的是集中保存不同同学取得的访谈、照片和观察，将其关联到空间对象，为比较陈述、识别共性与分歧，并结合现场观察、空间数据和其他资料进行交叉核验提供条件。最终判断仍需由学生在明确资料来源和分歧的基础上完成。

由于村民主要在线下接受访谈，并不作为共同研究者持续参与平台过程，本研究不宜宣称实施了完整的参与式行动研究。更准确的表述是：平台借鉴地方知识空间化和参与式调研的思想，支持学生整理和比较线下调查材料。后续还需完善证据来源、调查时间、核实状态、分歧记录和隐私保护。

### 2.2 空间可视化与真实任务学习

Sofias和Pierrakeas将WebGIS、项目式学习与现场数据采集结合，考察其对学生参与的影响[5]；Ruan等构建了包含学生端、教师端和管理端的地理实习平台，并比较不同教学组织模式[6]；Yin则讨论了三维可视化与GIS在规划教育中的结合，说明三维表达能够补充二维分析，并支持空间理解和协作学习[7]。这些研究本身并不只是评价孤立工具，而是已经尝试将技术与真实任务或课程活动结合。

不过，它们的研究重点与本研究并不相同：WebGIS项目主要评价学生参与，地理实习平台主要服务现场教学，三维GIS研究主要讨论课程设置和空间表达。这些成果能够支持真实任务、现场数据和二维三维互补的教学价值，但不能直接回答乡村规划课程中，调研材料怎样经过共享校核进入问题诊断和小组方案的问题。

本平台对这些研究的借鉴，是让二维地图主要承担现状校核、空间分析和方案编辑，让三维场景辅助体量、界面和场景判断，并尽量使用同一方案数据。同时，评价不只询问学生是否喜欢平台，还结合日志、版本和成果观察各功能怎样进入课程过程。

### 2.3 集成平台 数据互操作与贯穿式工作流

RINNO研究提出，复杂项目的困难往往不是缺少某项技术，而是人员、数据、工具和阶段能否被适当组合，并通过模块化、互操作和全周期工作流持续使用数据[8]。GeoDesign研究则展示了地理信息、方案生成、影响评价和协商过程在同一平台中的衔接[9]。

RINNO面向建筑改造，GeoDesign案例侧重协同设计工作坊，两者都不能直接作为教学效果的依据。本研究借鉴的是它们的数据贯通和工作流思想：通过统一空间对象关联调查材料与方案，通过共享现状基线建立共同起点，通过小组分支保留不同方案，并用日志和版本记录过程。目前“证据—问题—策略”的显式关系仍需完善，也不能把“课程任务全过程”扩大为乡村规划全生命周期。

### 2.4 综合评述与研究切入点

上述研究分别为地方知识获取、空间表达和平台工作流提供了依据。需要强调的是，本研究并不是在没有系统综述的情况下断言“现有研究普遍忽视”某个问题，而是指出目前选取的文献没有直接回答本研究的具体情境：在乡村规划实践课程中，学生取得的访谈、照片和观察怎样经过共享校核进入问题诊断，再继续进入小组方案和过程评价。

本研究因此关注三个连接问题：

1. **调研材料与空间对象的连接：**怎样集中、定位和比较不同学生取得的访谈、照片和观察，同时保留资料来源与分歧，为后续判断提供依据。
2. **班级共同现状与小组设计的连接：**全班怎样形成共享现状，各小组又怎样在同一基线上发展不同方案。
3. **学习过程与课程评价的连接：**怎样保存修改、讨论和版本演化，使评价不只面对最终图纸。

## 三 研究定位与平台思路

论文可暂定为“面向乡村规划实践教学的互动式学习平台构建与形成性评价”。规划教育是研究背景，乡村规划实践教学是具体场景，调研证据怎样进入共同空间认知和设计判断是核心过程。

核心科学问题可表述为：

> 本研究聚焦乡村规划实践教学中调研资料、空间表达工具与协作环节衔接不足的问题，探讨以统一空间对象、共享现状基线和版本化工作流为核心的数据贯通与流程协同机制，如何支持调研证据在“现状校核—问题诊断—方案推演”中的连续利用，并通过真实课堂检验其教学适用性与实施边界。

村民主要通过线下访谈提供地方信息；学生是平台主要使用者；教师确定课程要求；管理员根据教师意见完成配置、分组和现状冻结。平台总体过程为：

> 课程知识与真实村庄 → 调研证据空间化 → 班级共同校核 → 冻结共享现状 → 小组方案推演 → 过程记录与评价

## 四 平台操作流程

1. 教师与管理员确定村庄、任务、分组和阶段安排。
2. 学生学习理论和案例，并进入真实村庄空间辅助理解。
3. 学生利用遥感影像、开放地图和DEM数据，在个人空间生成和修订工作底图。
4. 学生开展踏勘和访谈，全班共同校核现状，并将照片、观察和访谈关联到空间对象。
5. 管理员按课程节点冻结共享现状，各小组从同一基线建立方案。
6. 小组开展问题诊断，在二维和三维环境中推演和比较方案。
7. 平台保存讨论、操作和版本，课程结束后结合成果、问卷和访谈进行评价。

## 五 平台可能产生的作用

对学生而言，平台可能帮助其在真实村庄中理解理论，认识数据核验和协作的重要性，并理解二维、三维和AI工具的适用范围。对课程而言，平台可以连接分散任务，并为过程评价提供日志和版本资料。对村庄而言，平台可以积累底图、调研材料和学生方案，但它不是正式治理系统，学生方案也不会自动成为实施方案。以上作用仍需课堂数据验证。

## 六 论文结构

论文可按照“提出问题—梳理研究—建立框架—设计平台—课堂实施—形成性评价—讨论结论”展开。

| 部分 | 主要内容 |
|---|---|
| 1 引言 | 说明规划教学中资料和环节衔接不足，提出研究问题、对象、方法与贡献，不展开国土空间规划制度背景。 |
| 2 文献综述 | 梳理参与式规划与地方知识、WebGIS与二维三维教学、集成平台与工作流，并提出三个连接问题。 |
| 3 理论与研究设计 | 界定调研证据、共同空间认知和设计判断，提出平台作用机制、数据来源、分析维度及伦理要求。 |
| 4 平台设计与实现 | 说明角色、数据结构和工作流，重点介绍对象关联、共享校核、冻结基线、小组分支、二维三维同源和版本记录。 |
| 5 课堂实施 | 说明课程情境、约15名学生、分组方式、教师与管理员分工，以及各阶段的实际使用过程。 |
| 6 实证分析 | 结合日志、版本、成果、问卷和访谈，分析流程适配、协作支持、知识连续性和使用障碍。 |
| 7 讨论与结论 | 回答科学问题，与已有研究对话，总结贡献、适用条件、局限和后续改进。 |

由于样本较小且预计没有严格的前后测和对照组，实证部分应定位为形成性评价，不宜声称平台显著提高了学习成绩。量化资料以描述统计和过程分布为主，质性资料采用成果追踪、典型案例和访谈主题分析，重点解释平台在哪些环节发挥作用、为什么发挥作用以及哪里仍然中断。研究方法可参考设计型研究对真实情境、迭代开发和多源证据的强调[10]。
